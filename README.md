A 2D top-down open-world crime game for the [gta6-01 bounty](https://make.fun/bounty/gta6-01).
You are Rook, a wheelman new to Solmar — a coastal city of downtown towers,
quiet suburbs, warehouses, a big park and a beach. Fixer Vera pays cash for
six missions; the Solmar PD pays attention.

## The city

Five districts on a 3600×2600 map: downtown, residential, industrial, the park
and the beach. Traffic follows the roads, pedestrians walk the sidewalks and
flee from gunfire. Everything is drawn in layered canvas sprites with soft
shadows, and the whole world is deterministic from a seed.

## Play

Drive, steal cars, run missions, lose the cops. Wanted level 0–5, police cars
and on-foot cops, shops (spray, arms, hospital), save to localStorage, pause
and restart. `?seed=` sets the world, `?shot=` jumps to a staged scene.

```sh
npm run serve   # serves the game on http://localhost:8080
```
